Timestep

Sets which weather-data sources are available below and which form of the Penman-Monteith equation is used (hourly vs. daily/monthly). Switching this clears any loaded data.

Source

NASA POWER auto-fetch is available for Daily and Monthly timesteps — its hourly solar-radiation data has a much longer processing latency and is often unavailable for recent dates. For Hourly, use Open-Meteo (below), Excel/CSV import, or manual entry.
Open-Meteo auto-fetch here is for the Hourly timestep. For Daily/Monthly, use NASA POWER above.
Uses the NASA POWER point API (power.larc.nasa.gov) at the coordinates set in Tab 1. Hourly requests are fetched in UTC and matched to the same clock internally, so results are unaffected by the UTC-offset field. Large hourly ranges (> ~31 days) may take a while — this call reaches an external server, so it only works when this page is open in your own browser (not in a sandboxed preview).
Uses the Open-Meteo historical weather API (archive-api.open-meteo.com) at the coordinates set in Tab 1 — no API key required, and (unlike NASA POWER's hourly product) solar radiation is available with only a few days' delay. Wind is measured at 10 m and converted to the standard 2 m reference height (FAO-56 log-wind-profile).
